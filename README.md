# Vinayak Barki Portfolio

A responsive single-page portfolio created from the supplied resume and profile photo.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Included
- Responsive portfolio UI
- Profile photo
- Resume download
- About, skills, experience, projects, education, certifications and contact sections
- LinkedIn and GitHub links
